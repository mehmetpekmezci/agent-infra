# Rust Testing

Test behavior rather than implementation details.

Consider:

- unit tests
- integration tests
- error paths
- boundary conditions
- concurrency behavior where applicable
- serialization/deserialization where applicable
- regression coverage

Run the project's normal test suite and report the exact validation performed.
