# Debugging

Do not start by changing code.

1. Reproduce.
2. Capture the failure.
3. Reduce the reproduction if practical.
4. Inspect logs, backtraces, tests, and relevant code.
5. Form a hypothesis.
6. Run an experiment that can falsify the hypothesis.
7. Identify root cause.
8. Propose or implement the smallest fix.
9. Add regression coverage.
