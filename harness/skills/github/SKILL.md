# GitHub Skill

Use the connected GitHub integration/MCP for remote repository operations.

## Common tasks

- inspect repository metadata and files
- inspect/search issues
- inspect/create pull requests
- inspect comments and reviews
- inspect CI/check status
- create branches or comments when requested
- inspect releases/tags

## Authentication

Credentials belong to the external tool/integration.
Never place tokens in `SKILL.md`, source code, workflow artifacts, or commits.
