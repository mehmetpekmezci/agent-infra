# Specification

## Goal

Remove ambiguity before implementation.

## Procedure

1. Restate the requested behavior.
2. Identify inputs, outputs, state changes, and external effects.
3. Define acceptance criteria that can be tested.
4. Identify edge cases.
5. Identify non-goals.
6. Record unresolved questions.

## Artifact

Create `spec.md` containing:

- Problem
- Requirements
- Acceptance criteria
- Constraints
- Edge cases
- Non-goals
- Open questions
